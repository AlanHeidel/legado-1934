Tipografía: combinar una serif editorial/vintage de alto contraste para títulos especiales y elementos de identidad (estilo Cormorant Garamond, DM Serif Display o similar) con una sans-serif gruesa, redondeada y retro para títulos principales (estilo Cooper Hewitt Heavy / Archivo Black / Bowlby One SC) y una sans-serif limpia y ligeramente condensada para textos y navegación (estilo Barlow Condensed).
Dirección visual: incorporar textura de papel/grano, pequeñas imperfecciones de impresión, pinceladas, manchas de tinta, bordes irregulares, elementos gráficos deportivos y composiciones editoriales. La estética debe sentirse artesanal, nostálgica y futbolera, pero con una interfaz web actual, limpia y funcional.
